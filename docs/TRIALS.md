# Qorx Trials

Qorx has two ways to start.

## Qorx Void Desktop

Use Void when the work lives on your computer.

You get a free 1-hour local demo. It is meant for the first real check: open a
workspace, let Qorx index it, watch the monitor, and ask for cited proof.

Good first jobs:

- coding with a local repo
- long AI sessions that keep repeating setup context
- notes, logs, policies, and local docs
- checking whether an answer is grounded in local files

Void does not include provider model usage. Your OpenAI, Anthropic, Gemini,
Cursor, or other provider account remains separate unless an enterprise
agreement says otherwise.

## Qorx Cloud API

Use Cloud API when the AI call lives in your product.

The free Developer path gives 5,000 hosted calls. It is enough to test the
optimizer, resolver handles, dashboard flow, and n8n-style automation without
starting with a paid plan.

Good first jobs:

- app or SaaS AI calls
- support bots
- dashboards
- n8n workflows
- internal tools that repeat the same setup text

## Founder Pricing

Founder pricing is intentionally capped:

- first 100 Qorx Void founders
- first 100 Qorx Cloud API founders

The cap exists to keep the early group small enough for support, feedback, and
proof. It is not a pressure timer. If the product is useful, try it. If the
counters do not help your workflow, do not buy it.

## Which One Should You Try?

| If your context is mostly... | Start with |
| --- | --- |
| Local repos, notes, logs, policies, AI editor sessions | Qorx Void Desktop |
| Hosted app traffic, bots, dashboards, n8n flows | Qorx Cloud API |
| Both | Void first, then API after the local flow makes sense |
