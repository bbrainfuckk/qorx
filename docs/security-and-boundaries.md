# Security And Boundaries

This repository is intentionally documentation only.

## Public

- Product explanation.
- Benchmark numbers.
- Scorecard labels and grades.
- Citation metadata.
- Security contact.
- Credits and research references.

## Private

Private material stays out of this repository. That includes unpublished product, engineering, release, customer, security, and operational material.

## Source Protection

The public GitHub branch is kept as a small documentation surface. It should not contain runnable programs, package artifacts, unpublished technical material, private assets, screenshots with secrets, credentials, or private logs.

Before publishing public changes, check that the branch contains only documentation and metadata files. The expected public file types are Markdown, citation metadata, license/notice text, and repository hygiene files.

## Third-Party Credit Boundary

Public credits name projects that influenced Qorx or provide useful public reference points. A credit is not a claim that Qorx copies, imports, redistributes, packages, or relicenses another project's code.

Kortex by Arjay is credited for helping shape the local-context direction behind Qorx. This is an attribution, not a dependency. Qorx is independently authored and uses a separate product architecture and implementation.

Do not copy, vendor, import, link, redistribute, or package Kortex source code into Qorx unless the owner gives written permission or the applicable license requirements are met.
