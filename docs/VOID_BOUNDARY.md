# Qorx Void publication boundary

Qorx Void is documented in this repository. Its proprietary source and
production internals are not published here.

## Public here

- the Qorx language, compiler, bytecode runtime, schemas, and public CLI source;
- Qorx Void product behavior and operator documentation;
- public command, MCP, integration, and security contracts;
- scoped benchmark summaries and sanitized reproducibility data;
- Qorx 1.0.6 package recipes and approved release assets;
- citations, research references, license, governance, and security policy.

## Excluded here

- Qorx Void desktop/service source and private kernel implementation;
- unpublished selection, routing, memory, or grounding algorithms;
- prompt libraries, model transcripts, private datasets, or evaluation material;
- customer systems, provider credentials, signing keys, and account ledgers;
- private deployment topology, build infrastructure, and release procedures;
- any internal binary or archive that has not passed a separate release audit.

The open Qorx source is enough to build and audit the public language and CLI.
It is not the proprietary Qorx Void product implementation.

respect the license and must not imply that they are the Qorx Void service.
