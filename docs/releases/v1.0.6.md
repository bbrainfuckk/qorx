# Qorx 1.0.6

Qorx 1.0.6 is the current public release line for the Qorx language, compiler,
portable bytecode runtime, and local evidence tools.

## Included

- `.qorx` parser, semantic checker, AST, QIR, and integrity-checked `.qorxb` bytecode;
- local context handles, evidence packs, grounding gates, Atlas, ORCL, MCP, and agent integrations;
- the `qorx eco` command and stable `qorx.eco.v1` JSON schema;
- compact-kernel command and artifact documentation for six x64/ARM64 targets;
- refreshed Qorx Void documentation with the full public tool inventory and scoped benchmark comparison;
- links to the three clean-room Qorx Zero hackathon editions;
- package metadata for Cargo, npm, PyPI, Arch/AUR, Homebrew, Debian, RPM, Snap, Scoop, WinGet, and Nix.

## Publication boundary

The release contains Qorx source and public documentation. It does not publish
proprietary Qorx Void source, private kernel implementation, unpublished
algorithms, prompts, signing operations, customer systems, or production release
procedures.

## Bootstrap status

The 1.0.6 compiler implementation is bootstrapped in Rust. Qorx source can be
checked, compiled, inspected, and run, but the compiler is not described as
self-hosted until the stage-1 and stage-2 reproducibility gate in
[`SELF_HOSTING.md`](../SELF_HOSTING.md) passes.

## Verify

```sh
cargo fmt --check
cargo test --locked
cargo clippy --all-targets -- -D warnings
cargo build --release --locked
qorx qorx-check examples/goal.qorx
qorx qorx-compile examples/goal.qorx --out goal.qorxb
qorx qorx goal.qorxb
qorx eco --local-tokens 13200000 --sent-tokens 8
```

Package channels are considered current only after their public package page or
GitHub release asset shows `1.0.6`.
