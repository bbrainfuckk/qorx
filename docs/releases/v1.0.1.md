# Qorx v1.0.1

Qorx v1.0.1 is a distribution release.

## Included

- Rust crate metadata for crates.io publication.
- npm and PyPI wrapper packages.
- Release asset workflow for Windows, Linux, and macOS binaries.
- Package recipes for Homebrew/Linuxbrew, AUR, Debian, RPM, Nix, Snap, Scoop,
  and WinGet.
- Install and distribution documentation.

## Boundary

The repository can carry packaging files without making every external package
index live. A channel is live only after its registry or package repository
accepts the package.

## Verification

Run:

```powershell
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
cargo package --allow-dirty
.\scripts\build-release-assets.ps1 -Version 1.0.1
```
