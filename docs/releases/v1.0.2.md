# Qorx v1.0.2

Qorx v1.0.2 is the production-readiness and registry-prep release.

## Changes

- Adds `qorx doctor --json` for operator readiness checks.
- Adds `qorx b2c-plan` and routes `qorx pack` through the deterministic B2C
  quant allocator.
- Adds local B2C planner headers to routed proxy responses:
  `x-qorx-cache-plan`, `x-qorx-cacheable-prefix-tokens`, and
  `x-qorx-dynamic-tail-tokens`.
- Adds `scripts/prepare-release.ps1` for repeatable Cargo, npm, PyPI, Arch/AUR,
  Homebrew, Scoop, WinGet, Debian, RPM, Snap, CITATION, Zenodo, and docs
  version updates.
- Adds handbook science notes and formula docs for the allocator, sparse
  retrieval, structural signals, squeeze, exact replay cache, provider cache
  accounting, KV hint boundaries, and USD accounting.
- Adds production and daemon documentation.
- Makes the daemon the official background runtime with `qorx daemon
  start|status|stop`; Windows tray is optional and controls the daemon.
- Adds the SAFE-R anti-hype gate so physics terms stay as Qorx vocabulary while
  claims stay tied to runtime evidence.
- Adds Docker, compose, systemd, and gateway smoke-test surfaces.
- Updates public author metadata to Marvin Sarreal Villanueva from Metro Manila.
- Adds public project contact emails: `marvin@orin.work` and `msarvillan@gmail.com`.
- Uses the scoped npm package name `@brainfukk/qorx`; the installed command is still `qorx`.

## Boundary

Qorx is production-ready as a local-first language runtime and internal service
component. It is not a public multi-user SaaS platform without an external auth,
network, backup, and monitoring layer.

The B2C allocator is local evidence selection. It is not a claim about revenue,
conversion lift, provider invoice savings, or task quality without matching
measurements.
