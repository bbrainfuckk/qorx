# Qorx 1.0.5

> **Historical release.** The current release is
> [Qorx 1.0.6](v1.0.6.md).

Qorx 1.0.5 shipped the language, compiler, portable bytecode runtime, and
local evidence resolver described below.

## Included

- `.qorx` parser and semantic checker
- AST and QIR lowering
- integrity-checked `.qorxb` bytecode
- local interpreter and `qorx://` resolver handles
- Windows, Linux, and macOS release targets for x64 and ARM64
- a 6 MiB maximum stripped executable size across release targets
- PyPI and npm launchers that select the matching release asset
- Arch/AUR, Homebrew, Scoop, WinGet, Snap, Docker, and Nix manifests

## Bootstrap status

The 1.0.5 compiler implementation was bootstrapped in Rust. It was not
represented as self-hosted until the reproducible
stage-1/stage-2 proof described in `docs/SELF_HOSTING.md` passes.

## Verify

```sh
cargo test --locked
cargo build --release --locked
qorx qorx-check examples/goal.qorx
qorx qorx-compile examples/goal.qorx --out goal.qorxb
qorx qorx goal.qorxb
```
