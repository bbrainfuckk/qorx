# Qorx v1.0.3

> **Historical release.** The current release is
> [Qorx 1.0.6](v1.0.6.md).

Qorx v1.0.3 introduced the SAFE-R claim checks.

## Changes

- Keeps Qorx physics vocabulary: quark, Cosmos, Redshift, photon,
  wavefunction, collapse, event horizon, Quetta, and subatomic.
- Documents those words as runtime labels, not physics claims.
- Adds `docs/SAFE-R.md`: Substantiated, Auditable, Falsifiable,
  Evidence-bound, Restricted-claims.
- Adds `scripts/safer-check.ps1` for repeatable claim, package, science,
  adapter, money-guard, provenance, secret, and unsafe-wording checks.
- Removes public slang and hype labels from the lexicon and integration text.
- Keeps daemon-first runtime behavior from v1.0.2.

## Boundary

Qorx v1.0.3 targeted controlled local and internal-service use. It was not a
public multi-user SaaS platform and required an external auth, network, backup,
and monitoring layer for server deployment.

Cosmos, Redshift, Quetta, and subatomic are Qorx vocabulary labels over local
runtime behavior. They are not physics claims, provider invoice claims, or proof
of task quality.
