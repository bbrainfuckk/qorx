# Qorx v0.0.1-ylem

Qorx v0.0.1-ylem is the current public line for the buildable CLI/runtime and
the docs that explain it.

The version number moved down. The capability did not.

## What This Line Keeps

- Local evidence indexing.
- Session carriers and context fault proof pages.
- Nano and Quetta compact carriers.
- Strict answer, squeeze, pack, map, Atlas, graph path, and ORCL.
- B2C allocator and local reduction accounting.
- Cache planning and exact replay cache boundaries.
- QORX source, protobuf bytecode, QIR, and stack tape.
- MCP stdio framing for agents.
- Science, adapter, benchmark, and SAFE-R claim checks.

## Why The Number Changed

The repo should read like an early, careful product line: small version, clear
boundary, real proof. Qorx is not downgrading the science to match the number.
It is putting the product back on a humble `ylem` line while keeping the tested
runtime.

## Proof

```powershell
cargo test --locked
cargo run --locked -- --version
cargo run --locked -- science
cargo run --locked -- bench --budget-tokens 900 "resolver boundary proof"
```

Expected version:

```text
qorx 0.0.1-ylem
```
