# Qorx 1.0.7

Qorx 1.0.7 is a small community update to the 1.0.6 line: one new command and one
connector fix. Everything from 1.0.6 is unchanged.

## New

- `qorx skills share` copies each skill folder (a folder with a `SKILL.md`) found
  in Claude Code, Codex, Antigravity or OpenCode into the others on this computer,
  so a skill you add in one tool works in all of them. Run it after adding or
  changing a skill.
  - Qorx marks its copies with a `.qorx-shared.json` file and never changes your
    own skill folders. Two different skills with the same name stay where they are.
  - A copy you edit becomes yours. A copy whose original you deleted is removed.
  - OpenCode reads `~/.claude/skills` itself, so its own folder is only read.
  - `qorx skills unshare` removes every copy Qorx made and nothing else.
  - `qorx skills share --json` prints the result as JSON.

## Fixed

- Antigravity: `qorx integrate activate --platform antigravity` now also writes
  `~/.gemini/config/mcp_config.json`, the file current Antigravity versions read,
  and `qorx integrate status` counts Antigravity as installed when its config
  folders exist (the Windows app puts no `antigravity` command on PATH).

## Install

```sh
cargo install --git https://github.com/bbrainfuckk/qorx --tag v1.0.7 --locked qorx
qorx --version
qorx skills share
```

A Windows x64 build is attached to the GitHub release.

## Publication boundary

As with 1.0.6, this release contains Qorx source and public documentation. It does
not publish proprietary Qorx Void source, private algorithms, prompts, signing
operations, customer systems, or production release procedures. Qorx Void, the
Windows app in the Microsoft Store, shares skills automatically and adds shared
notes across your AI tools.
