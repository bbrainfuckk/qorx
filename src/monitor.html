What Qorx does

Qorx keeps repeated workspace context on this computer and gives agents a small local handle when they need proof.

  • Less repeated context sent upstream.
  • Local proof before local claims.
  • Readable counters for what stayed here.
Agent context

Choose how much local guidance an agent receives at the start of a task.

  • Auto is the quiet default.
  • Readable shows the handoff note.
  • Deep is for hard local tasks.
  • Off sends nothing.
Editor connectors

MCP gives an agent a local tool. Hooks prepare the beginning of a task where the client supports it.

  • Fix rewrites Qorx-owned connector files.
  • MCP does not replace normal chat.
  • Agents still need proof for local claims.
Workspace Map

The map shows the files Qorx can search and the references it found between them.

  • Files appear as stars.
  • Lines are confirmed references.
  • Important files receive more links.
  • Other files remain searchable.
Proof boundary

A handle is not a file dump. Outside models cannot read local files from it by themselves.

  • Handles are not file contents.
  • Proof is pulled only on demand.
  • Unsupported claims must stay unsupported.
First run

Use these when a customer wants to install, check, or open the local runtime.

  • qorx
  • qorx --help
  • qorx man
  • qorx doctor
Install and repair

These commands match the Manual and Command Reference.

  • qorx install
  • qorx install -p codex
  • qorx integrate activate -p codex
  • qorx integrate status
Local runtime

The daemon is the local gateway behind this monitor.

  • qorx daemon start
  • qorx daemon status
  • qorx stats
  • qorx stats reset
Evidence commands

Use these when an agent needs local proof without reading the whole workspace.

  • qorx index <folder>
  • qorx map "question"
  • qorx strict-answer "question"
  • qorx ground "question"
Atlas commands

The map in this monitor is backed by the same local Atlas data.

  • qorx atlas
  • qorx atlas query "question"
  • qorx atlas export --out qorx-atlas
  • qorx atlas global list
